# Банкетам.Нет — Портал бронирования помещений для банкетов

Демонстрационный экзамен 2026  
Вариант № 4  
Код: В4_КОД 09.02.07-3-2026-ПУ  

Стек: **Node.js + Express + HTML/CSS/JS** (данные в JSON-файле)

## Описание

Информационная система для бронирования помещений:
- Зал
- Ресторан
- Летняя веранда
- Закрытая веранда

## Запуск

```bash
npm install
npm start
```

Откройте в браузере: http://localhost:3000

## Функционал

### Модуль 1
- Регистрация с валидацией (логин ≥6 лат. букв/цифр, пароль ≥8)
- Авторизация
- Личный кабинет с историей заявок
- Создание заявки (помещение, дата ДД.ММ.ГГГГ, способ оплаты)
- Панель администратора (изменение статусов: Новая → Банкет назначен → Банкет завершен)

### Модуль 2
- Дизайн по гайдлайну (цвета: золотой, розово-золотистый, кремовый, насыщенно-красный, тёмно-зелёный)
- Слайдер (4 изображения, автопереключение каждые 3 сек, кнопки вперёд/назад)
- Адаптация под 390×844

### Модуль 3
- Фильтры, сортировка, пагинация в админке
- Отзывы (только после смены статуса админом)
- Валидация форм с подсказками
- Микроанимации
- Мобильная адаптация

## Структура данных

- **users** — пользователи
- **applications** — заявки
- **reviews** — отзывы

Данные хранятся в `data/db.json` (создаётся автоматически).
