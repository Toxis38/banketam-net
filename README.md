## Описание

Информационная система для бронирования помещений:
- Зал
- Ресторан
- Летняя веранда
- Закрытая веранда

**Дополнительные услуги:** ведущий, шоколадный фонтан, фотограф, живая музыка/DJ, декор, торт на заказ, фейерверк, аниматор.

## Функционал

### Для гостей (без регистрации)
- Просмотр главной страницы
- Просмотр занятости помещений (`/occupancy.html`) — какие помещения заняты на какие даты
- **Нельзя** создавать заявки

### Для зарегистрированных пользователей
- Регистрация с валидацией (логин ≥6 лат. букв/цифр, пароль ≥8)
- Авторизация
- Личный кабинет с историей заявок
- Создание заявки (помещение, дата, способ оплаты, доп. услуги, кол-во гостей, комментарий)
- Проверка: нельзя забронировать уже занятое помещение на ту же дату
- Отзывы (только после смены статуса админом)

### Панель администратора
- Просмотр всех заявок
- Фильтры, сортировка, пагинация
- Изменение статусов: Новая → Банкет назначен → Банкет завершен
- Видит контактные данные клиентов и выбранные доп. услуги

## Структура данных

- **users** — пользователи
- **applications** — заявки (включая extra_services, guests_count, comment)
- **reviews** — отзывы

Данные хранятся в `data/db.json` (создаётся автоматически).
