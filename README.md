## Функционал

### Для гостей (без регистрации)
- Просмотр главной страницы с **ценами**
- Просмотр **планировки** (зал, ресторан, летняя/закрытая веранда) и занятости
- Выбор зоны и **столиков** на интерактивной карте
- **Нельзя** создавать заявки

### Для зарегистрированных пользователей
- Регистрация с валидацией (логин ≥6 лат. букв/цифр, пароль ≥8)
- Авторизация
- Личный кабинет с историей заявок, **итоговой суммой** и статусом оплаты
- Создание заявки: помещение, дата, гости, доп. услуги, столики, способ оплаты
- **Живой расчёт** стоимости: аренда + на гостей + услуги = итого
- Кнопка **«Оформить заказ»**
- При оплате картой МИР — форма карты; успешная оплата только тестовой картой **4111 1111 1111 1111**
- Проверка: нельзя забронировать уже занятое помещение на ту же дату
- Отзывы (только после смены статуса админом)

### Панель администратора
- Просмотр всех заявок с суммой и статусом оплаты
- Фильтры, сортировка, пагинация
- Изменение статусов: Новая → Банкет назначен → Банкет завершен
- Видит контактные данные клиентов, доп. услуги, столики

## Оплата (демо)

- **Оплата картой МИР**: номер `4111111111111111`, срок любой (ММ/ГГ), CVV любые 3 цифры → статус «оплачено»
- Другие карты → отклонение
- QR / постоплата — без ввода карты

## Структура данных

- **users** — пользователи
- **applications** — заявки (extra_services, guests_count, tables, total_amount, payment_status, comment)
- **reviews** — отзывы

Данные хранятся в `data/db.json` (создаётся автоматически).
